# Divyan Babbar - Portfolio

Personal portfolio site built with plain HTML, CSS, and JavaScript and published through GitHub Pages.

## Local preview

Open `index.html` in a browser. Project search and category filters run in the browser.

## Project accuracy

Project descriptions link to their public repositories. Simulated payment and remediation flows are labeled as simulations. The voice assistant entry describes the codebase and points to repository metadata for attribution.

## Deployment

The site is served from the `main` branch at the account's GitHub Pages address.
